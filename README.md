# Moon Beauty Parlor Website

A responsive multi-page demo website for a fictional beauty parlor in Multan.

## Pages
- Home
- About
- Services
- Gallery
- Blogs
- Contact

All business details are fictional sample content. The images in `images/` are bundled with the project so the website does not depend on missing image files.

Open `index.html` directly in a browser or serve the folder with a simple local server.
